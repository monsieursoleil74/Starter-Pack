PPTX → HTML interactif — version SANS EXE
(compatible Smart App Control / postes verrouillés)
====================================================

Cette version n'utilise AUCUN exe non signé : uniquement Python et
LibreOffice, tous deux signés par leurs éditeurs. Smart App Control
ne la bloque pas.

INSTALLATION (une seule fois)
1. Python : ouvre le Microsoft Store, cherche « Python 3.12 »
   (éditeur : Python Software Foundation) et installe-le.
   (Ou depuis python.org — coche alors « Add Python to PATH ».)
2. LibreOffice : https://fr.libreoffice.org (installateur signé)
3. Double-clique sur 1_INSTALLER.bat
   (installe les bibliothèques Python : python-pptx, tkinterdnd2, pymupdf)

UTILISATION
Double-clique sur 2_LANCER_TOOL.bat, puis dépose ton fichier .pptx
dans la fenêtre (Google Slides : Fichier → Télécharger → Microsoft
PowerPoint .pptx). La conversion démarre toute seule, le .html
apparaît à côté du .pptx et le dossier s'ouvre automatiquement.

100 % hors ligne : aucun contenu ne quitte la machine.

NOTE
Si le glisser-déposer ne fonctionne pas (bibliothèque tkinterdnd2
bloquée par la politique du poste), clique simplement dans la zone
pour choisir le fichier — tout le reste marche pareil.
