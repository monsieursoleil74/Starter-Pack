PPTX → HTML interactif — version SANS EXE
(compatible Smart App Control / postes verrouillés)
====================================================

Cette version n'utilise AUCUN exe ni script .bat : uniquement Python
et LibreOffice, tous deux signés par leurs éditeurs. Smart App Control
ne bloque rien.

INSTALLATION (une seule fois)
1. Python : ouvre le Microsoft Store, cherche « Python 3.12 »
   (éditeur : Python Software Foundation) et installe-le.
2. LibreOffice : https://fr.libreoffice.org (installateur signé)

UTILISATION
Double-clique sur PPTX2HTML.pyw — c'est tout.
Au tout premier lancement, une petite fenêtre installe les composants
(~1 min), puis l'application s'ouvre.

Ensuite : dépose ton fichier .pptx dans la fenêtre (Google Slides :
Fichier → Télécharger → Microsoft PowerPoint .pptx). La conversion
démarre toute seule, le .html apparaît à côté du .pptx et le dossier
s'ouvre automatiquement.

Astuce : tu peux aussi déposer le .pptx directement sur l'icône de
PPTX2HTML.pyw, et créer un raccourci vers ce fichier sur le Bureau.

RENDRE LA PRÉSENTATION INTERACTIVE
Ouvre le .html obtenu et clique sur ✏️ en haut à droite (ou touche E) :
- ➕ Zone : dessine un bouton sur la diapo (aller à une diapo précise,
  suivante/précédente, retour, ouvrir un lien, lire une vidéo).
- 👁 sur une vignette : cache la diapo — elle sort du fil de lecture et
  n'est plus accessible QUE via un bouton qui pointe dessus.
- 🎬 Vidéo : incruste une vidéo (fichier local ou lien YouTube).
- Glisse pour déplacer, poignée orange pour redimensionner, Suppr efface.
Puis 💾 Enregistrer : le navigateur retélécharge le .html à jour —
remplace l'ancien fichier par celui-ci. 🔒 Export final donne une copie
sans mode édition, à diffuser.

Les liens déjà posés dans Google Slides (sauts de diapo, URLs, vidéos
YouTube) sont repris automatiquement à la conversion. Reconvertir le même
.pptx écrase le .html : renomme ton HTML édité pour le garder.

100 % hors ligne : aucun contenu ne quitte la machine
(la première installation des composants est le seul moment où
Python télécharge des bibliothèques — aucune de tes données ne part).

NOTE
Si le glisser-déposer ne fonctionne pas sur ton poste, clique
simplement dans la zone pour choisir le fichier.
