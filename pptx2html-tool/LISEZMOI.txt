PPTX → HTML interactif — version Windows (exe)
================================================

DÉMARRAGE RAPIDE
1. Installe LibreOffice (une seule fois) : https://fr.libreoffice.org
   L'outil s'en sert en arrière-plan pour rendre les slides.
   Rien n'est envoyé en ligne : tout se passe sur ta machine.
2. Ouvre PPTX2HTML.exe
3. Dépose ton fichier .pptx dans la fenêtre
   (Google Slides : Fichier → Télécharger → Microsoft PowerPoint .pptx)
   → la conversion démarre toute seule, le .html apparaît à côté du .pptx
   et le dossier s'ouvre automatiquement.

ASTUCES
- Tu peux aussi déposer le .pptx directement sur l'icône de PPTX2HTML.exe.
- Plusieurs fichiers d'un coup : ils sont convertis à la suite.
- Si LibreOffice manque, un bouton rouge « Installer LibreOffice »
  apparaît dans la fenêtre.

IMPORTANT
- Premier lancement : Windows SmartScreen peut afficher un avertissement
  « éditeur inconnu » → clique sur « Informations complémentaires »
  puis « Exécuter quand même ».
- Si ton PC utilise SMART APP CONTROL (Windows 11) : il bloque tous les
  exe non signés SANS possibilité d'exception. Deux options :
  a) télécharge plutôt « PPTX2HTML-Windows-SansExe.zip » depuis la même
     page (aucun exe — Python signé du Microsoft Store + scripts), ou
  b) désactive Smart App Control (Paramètres → Confidentialité et
     sécurité → Sécurité Windows → Contrôle des applications et du
     navigateur) — attention, c'est irréversible sans réinstaller Windows.
- Le premier rendu peut prendre une minute (démarrage de LibreOffice).
